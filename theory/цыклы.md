# Полный гайд по циклам в C++
# ЧАСТЬ 0. Зачем нужны циклы

`if` и `switch` выполняются **один раз**. Цикл — **многократное повторение блока**, пока выполняется условие.

**Аналогия:** «пока не сварилось — помешивай».

---

# ЧАСТЬ 1. Три вида циклов — обзор

| Цикл | Когда проверяется условие | Может выполниться 0 раз? |
|------|---------------------------|--------------------------|
| `for` | **до** каждой итерации | Да |
| `while` | **до** каждой итерации | Да |
| `do-while` | **после** каждой итерации | **Нет** (минимум 1 раз) |

Плюс:
- `break` — выйти из цикла немедленно.
- `continue` — пропустить остаток итерации и перейти к следующей.
- `goto` — устаревший, но существует.

# ЧАСТЬ 2. Цикл `while`

## 2.1. Синтаксис

```cpp
while (условие) {
    // тело — повторяется, пока условие истинно
}
```

**Порядок:** проверить условие → если истина, выполнить тело → вернуться к проверке → если ложь, выйти.

## 2.2. Шаблон A — «накопитель»

Создать накопитель **до** цикла, обновлять **в** цикле, использовать **после**.

```cpp
int sum = 0;                    // накопитель ДО цикла
int x;
std::cin >> x;

while (x != 0) {                // пока не введён 0
    sum = sum + x;              // обновляем В цикле
    std::cin >> x;
}

std::cout << "Сумма: " << sum << "\n";   // используем ПОСЛЕ
```

## 2.3. Шаблон B — «ввод с проверкой»

Спрашивать, пока не введут корректно. Связка `clear()` + `ignore()` — обязательна.

```cpp
int age;
std::cout << "Возраст (0..150): ";
std::cin >> age;

while (std::cin.fail() || age < 0 || age > 150) {
    std::cin.clear();                   // сброс ошибки
    std::cin.ignore(10000, '\n');       // очистка буфера
    std::cout << "Некорректно. Возраст (0..150): ";
    std::cin >> age;
}

std::cout << "Принято: " << age << "\n";
```

## 2.4. Главная ошибка — бесконечный цикл

```cpp
int i = 1;
while (i <= 5) {
    std::cout << i << "\n";
    // ЗАБЫЛИ i = i + 1; → i всегда 1 → бесконечность
}
```

**Правило:** внутри цикла должно быть действие, которое рано или поздно сделает условие ложным.

# ЧАСТЬ 3. Цикл `for`

## 3.1. Синтаксис

```cpp
for (инициализация; условие; шаг) {
    // тело
}
```

**Порядок:**
1. Инициализация (один раз).
2. Проверить условие. Ложь → выход.
3. Выполнить тело.
4. Выполнить шаг.
5. Вернуться к шагу 2.

Сокращённые формы шага:

| Запись | Значение |
|--------|----------|
| `i = i + 1` / `i += 1` / `i++` / `++i` | +1 |
| `i--` | −1 |
| `i += 3` | +3 |
| `i *= 2` | ×2 |

## 3.2. Шаблон A — «счётчик с накоплением»

```cpp
int sum = 0;                                // накопитель ДО
for (int i = 1; i <= n; i++) {
    sum += i;                               // обновляем В
}
std::cout << "Сумма: " << sum << "\n";      // используем ПОСЛЕ
```

## 3.3. Шаблон B — «найти и прервать»

```cpp
int foundAt = -1;                           // -1 = "не найден"
for (int i = 0; i < 100; i++) {
    if (i * i == target) {
        foundAt = i;                        // запомнили
        break;                              // дальше не ищем
    }
}
if (foundAt == -1) std::cout << "Не найдено\n";
else               std::cout << "Найдено: " << foundAt << "\n";
```

## 3.4. Необязательные части

```cpp
int i = 1;
for (; i <= 5; i++) { ... }         // инициализация снаружи
for (int i = 1; i <= 5; ) { ... }   // шаг внутри тела
for (;;) { ... }                     // бесконечный (нужен break)
```

# ЧАСТЬ 4. Цикл `do-while`

## 4.1. Синтаксис

```cpp
do {
    // тело
} while (условие);      // ОБЯЗАТЕЛЬНО точка с запятой!
```

**Порядок:** выполнить тело **безусловно** → проверить условие → если истина, вернуться к телу.

## 4.2. Шаблон A — «меню»

Меню должно показаться **хотя бы раз** — поэтому `do-while`.

```cpp
int choice;
do {
    std::cout << "\n1. Привет\n2. Пока\n0. Выход\nВыбор: ";
    std::cin >> choice;

    if (std::cin.fail()) {
        std::cin.clear(); std::cin.ignore(10000, '\n');
        choice = -1;
    }

    if      (choice == 1) std::cout << "Привет!\n";
    else if (choice == 2) std::cout << "Пока!\n";
    else if (choice == 0) std::cout << "Выходим...\n";
    else                  std::cout << "Неверно\n";

} while (choice != 0);
```

## 4.3. Шаблон B — «ввод с проверкой через флаг»

```cpp
int age;
bool ok = false;
do {
    std::cout << "Возраст (0..150): ";
    std::cin >> age;
    if (std::cin.fail() || age < 0 || age > 150) {
        std::cin.clear(); std::cin.ignore(10000, '\n');
        std::cout << "Некорректно!\n";
    } else {
        ok = true;
    }
} while (!ok);
```

## 4.4. Частая ошибка

```cpp
do { ... } while (false)     // ОШИБКА: нет ;
```

# ЧАСТЬ 5. `break` — немедленный выход

## 5.1. Что делает

`break` **мгновенно** прерывает цикл, не дожидаясь проверки условия.

## 5.2. Шаблон A — «ранний выход по условию»

```cpp
for (int i = 1; i <= 100; i++) {
    if (i == 5) break;              // выходим прямо здесь
    std::cout << i << "\n";         // выведет 1..4
}
std::cout << "После цикла\n";
```

## 5.3. Шаблон B — «бесконечный цикл + break»

Нормальный паттерн, когда условие выхода сложное или лежит глубоко внутри.

```cpp
while (true) {                      // бесконечно
    std::string line;
    std::cout << "> ";
    std::getline(std::cin, line);

    if (line == "exit") break;      // единственный выход
    std::cout << "Вы ввели: " << line << "\n";
}
```

## 5.4. Не путать: `break` в `switch` ≠ `break` в цикле

- В `switch` — предотвращает «провал» в следующий `case`.
- В цикле — прерывает цикл.

`break` внутри `switch`, который сам внутри цикла, прерывает **только `switch`**, а не цикл.

# ЧАСТЬ 6. `continue` — пропустить остаток итерации

## 6.1. Что делает

`continue` пропускает **весь оставшийся код тела** и переходит:
- в `for` — к шагу, потом к условию;
- в `while` / `do-while` — сразу к проверке условия.

## 6.2. Шаблон A — «пропуск по условию»

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;           // 3 не выведется
    std::cout << "i = " << i << "\n";
}
// 1, 2, 4, 5
```

## 6.3. Шаблон B — «ранний пропуск с последующей обработкой»

```cpp
for (int i = 0; i < 5; i++) {
    std::string line;
    std::getline(std::cin, line);

    if (line.empty()) continue;     // ранний пропуск
    std::cout << "Длина: " << line.length() << "\n";
}
```

Полезен, когда после `continue` идёт **большой** блок — иначе код уходит вправо.

## 6.4. Ловушка: `continue` в `while`

```cpp
int i = 0;
while (i < 5) {
    if (i == 2) continue;           // i НЕ увеличится → бесконечность!
    i++;
}
```

**Правило:** в `while`/`do-while` изменение счётчика должно быть **до** `continue`. В `for` этой проблемы нет — шаг выполняется автоматически.

# ЧАСТЬ 7. Вложенные циклы

## 7.1. Идея

Внутренний цикл выполняется **полностью** на каждой итерации внешнего.

**Аналогия:** часы. Часовая стрелка делает 1 шаг — минутная делает 60.

## 7.2. Шаблон A — «двумерная таблица»

```cpp
for (int i = 1; i <= 5; i++) {          // строка
    for (int j = 1; j <= 5; j++) {      // столбец
        std::cout << std::setw(4) << i * j;
    }
    std::cout << "\n";                  // \n — ПОСЛЕ внутреннего цикла
}
```

**Разбор:** внешний — строки, внутренний — столбцы. `\n` — после внутреннего, чтобы закончить строку.

## 7.3. Шаблон B — «досрочный выход из обоих через флаг»

`break` во вложенном прерывает **только внутренний**. Для выхода из обоих — флаг:

```cpp
bool stop = false;
for (int i = 1; i <= 3 && !stop; i++) {     // условие с флагом
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) { stop = true; break; }
        std::cout << "(" << i << "," << j << ") ";
    }
}
```

# ЧАСТЬ 8. `goto` (кратко, чтобы знать)

`goto` — безусловный переход по метке. В современном коде **не используется** — есть `break`/`continue`/флаги/функции.

```cpp
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) goto end;
        std::cout << "(" << i << "," << j << ") ";
    }
}
end:
std::cout << "\nКонец\n";
```

**Не используй `goto`, пока не поймёшь почему.**

# ЧАСТЬ 9. Шпаргалка

## 9.1. Синтаксис

```cpp
for (int i = 0; i < N; i++) { ... }
while (условие) { ... }
do { ... } while (условие);      // ! точка с запятой
break;                            // немедленный выход
continue;                         // пропустить остаток итерации
```

## 9.2. Шаблоны (по 2 на тему)

| Тема | Шаблон A | Шаблон B |
|------|----------|----------|
| `while` | накопитель | ввод с проверкой |
| `for` | счётчик с накоплением | найти и прервать |
| `do-while` | меню | ввод с проверкой через флаг |
| `break` | ранний выход по условию | бесконечный цикл + break |
| `continue` | пропуск по условию | ранний пропуск с обработкой |
| вложенные | двумерная таблица | выход из обоих через флаг |

## 9.3. Частые ошибки

| Ошибка | Лечение |
|--------|---------|
| Забыл `i++` в `while` | Условие должно рано или поздно стать ложным |
| `do-while` без `;` | Добавь `;` после `while (...)` |
| `continue` в `while` до `i++` | Измени счётчик **до** `continue` |
| `break` во вложенном прерывает только внутренний | Используй флаг |
| `cin >>` без `fail()` | Всегда проверяй `std::cin.fail()` |
| Забыл `ignore()` после `cin >>` перед `getline` | `std::cin.ignore(10000, '\n');` |
| `i <= n` вместо `i < n` | Перечитай границы — ошибка «на 1» |
