# Полное руководство по типам данных, переменным и преобразованиям в C++

## Часть первая: Переменные, ввод-вывод и операции

### 1. Что такое переменная

Переменная — это именованная область памяти. При объявлении переменной вы сообщаете компилятору: «мне нужно место для хранения данных такого-то типа, и я буду обращаться к нему по этому имени».

```cpp
int age;           // объявление без инициализации, значение не определено (локальная переменная)
int score = 100;   // объявление с инициализацией
double pi = 3.14159;
char grade = 'A';
bool isPassed = true;
```

**Важное правило**: локальные переменные без инициализации содержат «мусорное значение» (неопределённое поведение), глобальные и статические переменные по умолчанию инициализируются нулём.

### 2. Вывод и ввод

**Вывод** использует `std::cout` и оператор `<<`:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name = "Alice";
    int age = 25;
    std::cout << "Name: " << name << ", Age: " << age << std::endl;
    // std::endl выводит новую строку и сбрасывает буфер
    return 0;
}
```

**Ввод** использует `std::cin` и оператор `>>`. Следует учитывать: `cin >>` автоматически пропускает ведущие пробелы и останавливается при встрече с пробелом, табуляцией или новой строкой — то есть читает одно «слово», а не всю строку .

```cpp
int num;
std::string word;
std::cin >> num;        // читает целое число
std::cin >> word;       // читает слово (до пробела)
```

**Чтение целой строки** (включая пробелы) требует `std::getline`:

```cpp
std::string fullName;
std::cout << "Enter your full name: ";
std::getline(std::cin, fullName);  // читает всю строку до '\n'
```

**Классическая ловушка**: при смешанном использовании `cin >>` и `getline` в буфере остаётся символ новой строки, из-за чего `getline` сразу возвращает пустую строку . Решение — вызвать `cin.ignore()` для очистки буфера:

```cpp
int n;
std::cin >> n;
std::cin.ignore();          // игнорируем оставшийся '\n'
std::string line;
std::getline(std::cin, line);  // теперь читаем нормально
```

### 3. Операции с переменными

**Арифметические операторы**: `+ - * / %`. Обратите внимание: при делении целых чисел результат отбрасывает дробную часть (`7 / 2` равно `3`). Для получения дробного результата хотя бы один операнд должен быть числом с плавающей точкой.

**Составное присваивание**: `+= -= *= /= %=`.

**Инкремент и декремент**: `++` и `--` имеют префиксную и постфиксную формы, разница существенна:

```cpp
int a = 5;
int b = a++;   // b = 5, a = 6 (сначала использовать, потом увеличить)
int c = ++a;   // a = 7, c = 7 (сначала увеличить, потом использовать)
```

**Операторы сравнения**: `== != < > <= >=`, результатом является `bool` (true/false).

**Логические операторы**: `&&` (и), `||` (или), `!` (не). Обратите внимание на разницу между `=` (присваивание) и `==` (сравнение) — это одна из самых частых ошибок у начинающих.

## Часть вторая: Полный разбор системы типов данных

### 1. Фундаментальные типы (Fundamental Types)

C++ — строго типизированный язык, каждый тип имеет фиксированный размер, но **конкретный размер зависит от реализации** (компилятора и платформы). Для получения точного размера используйте `sizeof` .

#### Целочисленные типы

| Тип | Типичный размер | Диапазон значений (типичный) |
|---|---|---|
| `short` | 2 байта | -32,768 ~ 32,767 |
| `int` | 4 байта | -2,147,483,648 ~ 2,147,483,647 |
| `long` | 4 или 8 байт | зависит от платформы |
| `long long` | 8 байт | -9.22e18 ~ 9.22e18 |
| `unsigned int` | 4 байта | 0 ~ 4,294,967,295 |

Стандарт C++ не гарантирует фиксированную разрядность `int`. Для точного контроля разрядности используйте типы фиксированной ширины из `<cstdint>`: `int32_t`, `uint64_t` и т.д. .

#### Типы с плавающей точкой

| Тип | Типичный размер | Точность |
|---|---|---|
| `float` | 4 байта | около 6-7 значащих цифр |
| `double` | 8 байт | около 15-16 значащих цифр |
| `long double` | 8/12/16 байт | выше, чем у double |

**Ключевое понятие**: числа с плавающей точкой не могут точно представить все десятичные дроби. `0.1 + 0.2 != 0.3` — это распространённое явление в C++. Сравнение чисел с плавающей точкой следует выполнять с допуском:

```cpp
#include <cmath>
bool almostEqual(double a, double b) {
    return std::fabs(a - b) < 1e-9;
}
```

#### Символьные типы

`char` — один байт, обычно представляет символ в кодировке ASCII (или локальной кодировке). `'A'` — это символ, `65` — соответствующее ему целое значение (в ASCII). Существует неявное преобразование между `char` и целыми числами, но не следует злоупотреблять этим.

`wchar_t` используется для расширенных наборов символов (например, Unicode), в Windows обычно 2 байта, в Linux — 4 байта.

#### Логический тип

`bool` принимает только два значения: `true` и `false`. При выводе по умолчанию выводится `1` или `0`; для вывода `true`/`false` используйте `std::boolalpha` :

```cpp
std::cout << std::boolalpha << (5 > 3);  // выводит true
```

### 2. Составные типы

**Массивы**: набор элементов одного типа с непрерывным расположением в памяти, размер фиксирован на этапе компиляции (для встроенных массивов). Индексация начинается с 0, C++ **не проверяет границы** .

```cpp
int arr[5] = {1, 2, 3, 4, 5};
// arr[5] — выход за границы, неопределённое поведение!
```

**Указатели**: хранят адрес памяти. `int* p = &x;` получает адрес x. Разыменование `*p` получает значение по адресу.

**Ссылки**: псевдонимы переменных, должны быть инициализированы при объявлении и не могут быть переназначены на другую переменную. Часто используются для параметров функций для избежания копирования.

### 3. Пользовательские типы

**Перечисления** `enum`: именованные целочисленные константы.

```cpp
enum Color { RED, GREEN, BLUE };  // RED=0, GREEN=1, BLUE=2
Color c = RED;
```

`enum class` (scoped enum, C++11) безопаснее, не происходит неявного преобразования в int.

**Структуры** `struct`: несколько переменных разных типов, объединённых вместе.

**Классы** `class`: структуры с инкапсуляцией (члены по умолчанию private).

## Часть третья: Полный разбор преобразования типов

### 1. Неявное преобразование (Implicit Conversion)

Компилятор автоматически выполняет преобразование, когда типы не совпадают. Основное правило: **преобразование в более широкий тип (widening)** обычно безопасно, **преобразование в более узкий тип (narrowing)** может привести к потере данных.

```cpp
int i = 42;
double d = i;        // int -> double, безопасно, 42.0
float f = 3.14;      // double -> float, может потерять точность
int j = 3.99;        // double -> int, дробная часть отбрасывается, j = 3
char ch = 'A' + 1;   // 'A' неявно преобразуется в int 65, 65+1=66, затем в char 'B'
```

**Целочисленные повышения (Integer Promotion)**: в выражениях `char`, `short` и `bool` автоматически повышаются до `int`. Это объясняет, почему `char + char` возвращает `int`.

**Целочисленное преобразование с потерей данных**:

```cpp
int big = 300;
char c = big;   // 300 не помещается в char (максимум 127 или 255), результат зависит от реализации
// Типичный результат: 300 - 256 = 44 (при условии 8-битного char)
```

**Преобразование знакового и беззнакового**: при сравнении `int` и `unsigned int` знаковое автоматически преобразуется в беззнаковое. Отрицательное число преобразуется в очень большое положительное, что приводит к «ошибке» :

```cpp
int a = -1;
unsigned int b = 1;
if (a < b) { /* может не выполниться! -1 преобразуется в 4294967295 */ }
```

### 2. Явное преобразование (Explicit Conversion / Cast)

C++ предоставляет четыре именованных оператора приведения типов, которые более читаемы и безопасны, чем стиль C.

**static_cast**: наиболее часто используемый, для «разумных» преобразований, проверяемых на этапе компиляции.

```cpp
double d = 3.99;
int i = static_cast<int>(d);          // отбрасывание дробной части, i = 3
int j = static_cast<int>(3.14 + 2.0); // преобразование результата выражения
char c = static_cast<char>(65);       // 65 -> 'A'
```

### 3. Преобразования в строках и числах

**Строка → число**: `std::stoi`, `std::stod`, `std::stol` и т.д. (C++11).

```cpp
#include <string>
std::string s = "123";
int n = std::stoi(s);        // 123
double d = std::stod("3.14"); // 3.14
// при ошибке генерируется std::invalid_argument или std::out_of_range
```

**Число → строка**: `std::to_string`.

```cpp
std::string s1 = std::to_string(42);      // "42"
std::string s2 = std::to_string(3.14);    // "3.140000" (по умолчанию 6 знаков)
```

### 4. Сводная таблица сценариев преобразования

| Сценарий | Метод | Риски |
|---|---|---|
| int → double | неявное/static_cast | нет |
| double → int | static_cast | потеря дробной части |
| int → char | static_cast | переполнение, усечение |
| signed → unsigned | неявное | отрицательные значения становятся большими положительными |
| базовый указатель → производный указатель | dynamic_cast | проверка во время выполнения, возвращает nullptr |
| удаление const | const_cast | запись константного объекта — UB |
| указатель ↔ целое | reinterpret_cast | непереносимо |

## Часть четвёртая: 10 упражнений

**Упражнение 1: Определение размера типов**
Напишите программу, которая использует `sizeof` для вывода размеров (в байтах) `char`, `short`, `int`, `long`, `long long`, `float`, `double`, `bool` на вашей платформе. Подумайте: какие из них гарантированы стандартом C++, а какие зависят от реализации?

**Упражнение 2: Ловушка целочисленного деления**
Пользователь вводит два целых числа a и b. Вычислите a/b и выведите результат. Затем измените код так, чтобы выводился точный результат деления с плавающей точкой (например, 7/2 выводит 3.5).

**Упражнение 3: Неявное преобразование и потеря данных**
Объявите `int big = 1000;`, затем `char small = big;`. Выведите значение `small`. Объясните, почему результат именно такой (подсказка: рассмотрите двоичное представление и усечение).

**Упражнение 4: Сравнение знакового и беззнакового**
Объявите `int a = -1;` и `unsigned int b = 1;`. Напишите `if (a < b)`, выведите результат. Объясните, почему результат может не соответствовать интуиции, и как исправить код (подсказка: используйте static_cast для явного преобразования).

**Упражнение 5: Исправление ловушки getline**
Пользователь сначала вводит целое число n, затем строку (которая может содержать пробелы). Исправьте следующий код с ошибкой:
```cpp
int n;
std::cin >> n;
std::string line;
std::getline(std::cin, line);  // проблема: line пустая
```

**Упражнение 6: Разница между префиксным и постфиксным инкрементом**
Напишите код: `int i = 10; int a = i++; int b = ++i;` Выведите значения a, b, i. Затем объясните на примере, почему `i++` и `++i` в цикле for обычно дают одинаковый результат, но в некоторых контекстах различия.

**Упражнение 7: Точность float**
Напишите программу для проверки: равно ли `0.1 + 0.2` значению `0.3`? Выведите результат. Затем напишите функцию для определения «примерного равенства» двух чисел с плавающей точкой (с допуском 1e-9), проверьте `0.1+0.2` и `0.3`.

**Упражнение 8: static_cast против reinterpret_cast**
Объявите `double d = 3.14;`. Используйте `static_cast<int>(d)` для получения целого числа и вывода.

**Упражнение 9: Строка ↔ число**
Напишите программу: прочитайте строку с клавиатуры, используйте `std::stoi` для преобразования в целое число и выведите удвоенное значение. Если пользователь вводит нечисловую строку (например, "abc"), перехватите исключение и выведите сообщение об ошибке. Затем используйте `std::to_string` для преобразования целого числа 255 в строку и выведите.

**Упражнение 10: Диапазон unsigned char**
Объявите `unsigned char c = 250;`, затем `c += 10;`. Выведите значение `c`. Объясните, почему результат не 260 (подсказка: диапазон unsigned char составляет 0~255, переполнение вызывает циклический переход). Затем используйте `int` для правильного вычисления и вывода 260.

## Заключение

Ключевые моменты типов данных C++: **размер типов зависит от реализации**, **неявное преобразование имеет риски**, **именованные приведения типов более безопасны**, **числа с плавающей точкой не могут сравниваться на точное равенство**, **знаковые и беззнаковые смешанные операции — распространённый источник ошибок**. Овладение этими основами — обязательное условие для написания корректного кода на C++.
