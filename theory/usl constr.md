# Полное руководство по условным конструкциям в C++
В C++ есть: `if`, `if-else`, `if-else if-else`, тернарный оператор `?:`, `switch`, а также логические операторы `&&`, `||`, `!` и операторы сравнения.

---

## Часть 1. `if`

Простейшая форма: выполнить блок, если условие истинно.

```cpp
#include <iostream>

int main() {
    int number;
    std::cout << "Введите число: ";
    std::cin >> number;

    if (number > 0) {
        std::cout << "Число положительное\n";
    }

    std::cout << "Конец программы\n";   // выполнится всегда
    return 0;
}
```

**Синтаксис:**
```
if (условие) {
    // блок выполняется, если условие != 0
}
```

Фигурные скобки можно опустить, если в блоке **одна** инструкция:

```cpp
if (number > 0)
    std::cout << "положительное\n";
```

Но **лучше всегда писать скобки** — это защищает от ошибок при добавлении второй строки.

## Часть 2. Логические выражения и тип `bool`

Теперь, когда базовая форма `if` понятна, разберёмся, **что именно проверяется**. В C++ любое выражение, использованное в условии, приводится к `bool`:

- `0` → `false`
- любое ненулевое значение → `true`
- `false` → `false`, `true` → `true`

```cpp
#include <iostream>

int main() {
    int x = 0;
    if (x) {                        // 0 приводится к false
        std::cout << "не выполнится\n";
    }

    x = -5;
    if (x) {                        // -5 != 0 → true
        std::cout << "выполнится\n";
    }

    double d = 0.0001;
    if (d) {                        // 0.0001 != 0 → true
        std::cout << "d ненулевое\n";
    }

    return 0;
}
```

**Важно:** `bool` при выводе через `std::cout` по умолчанию печатается как `1`/`0`. Чтобы увидеть `true`/`false`, используйте `std::boolalpha`:

```cpp
std::cout << std::boolalpha << (5 > 3);   // true
```

### 2.1. Операторы сравнения

| Оператор | Значение |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `<` | меньше |
| `>` | больше |
| `<=` | меньше или равно |
| `>=` | больше или равно |

```cpp
int a = 5, b = 7;
std::cout << std::boolalpha;
std::cout << (a == b) << "\n";   // false
std::cout << (a != b) << "\n";   // true
std::cout << (a <  b) << "\n";   // true
std::cout << (a >= b) << "\n";   // false
```

**Классическая ошибка:** `=` (присваивание) вместо `==` (сравнение).

```cpp
int x = 5;
if (x = 0) {            // ПРИСВАИВАНИЕ! x становится 0, условие false
    // не выполнится
}
// Компилятор может выдать предупреждение, но код скомпилируется
```

### 2.2. Логические операторы

| Оператор | Название | Результат `true`, когда… |
|---|---|---|
| `&&` | И (AND) | оба операнда истинны |
| `\|\|` | ИЛИ (OR) | хотя бы один истинен |
| `!` | НЕ (NOT) | операнд ложен |

```cpp
int age = 20;
bool hasTicket = true;

if (age >= 18 && hasTicket) {
    std::cout << "Можно войти\n";      // оба условия истинны
}

if (age < 18 || !hasTicket) {
    std::cout << "Нельзя войти\n";     // не выполнится
}
```

**Короткое замыкание (short-circuit):** `&&` не вычисляет правый операнд, если левый `false`; `||` не вычисляет правый, если левый `true`. Это важно, если правый операнд имеет побочные эффекты или может быть опасен (например, деление на ноль).

```cpp
int b = 0;
if (b != 0 && 10 / b > 1) {   // 10/b не вычисляется, т.к. b != 0 → false
    // безопасно
}
```

### 2.3. Приоритет операторов (кратко)

От высокого к низкому (только нужное здесь):
`!` → сравнения (`<`, `>`, `<=`, `>=`) → `==`, `!=` → `&&` → `||`.

Поэтому `a > 0 && b > 0` читается как `(a > 0) && (b > 0)`. Но если сомневаетесь — ставьте скобки: это не ошибка и повышает читаемость.

## Часть 3. `if-else`

Позволяет выполнить одну из двух веток.

```cpp
#include <iostream>

int main() {
    int number;
    std::cout << "Введите число: ";
    std::cin >> number;

    if (number % 2 == 0) {
        std::cout << "Чётное\n";
    } else {
        std::cout << "Нечётное\n";
    }

    return 0;
}
```

**Синтаксис:**
```
if (условие) {
    // ветка «истина»
} else {
    // ветка «ложь»
}
```

### 3.1. Вложенные `if`

```cpp
int a = 10, b = 20;

if (a > 0) {
    if (b > 0) {
        std::cout << "оба положительные\n";
    } else {
        std::cout << "a > 0, b <= 0\n";
    }
} else {
    std::cout << "a <= 0\n";
}
```

**Проблема «висячего else»:** `else` всегда связывается с **ближайшим** предшествующим `if`, у которого ещё нет `else`. Поэтому всегда используйте фигурные скобки.

```cpp
if (a > 0)
    if (b > 0)
        std::cout << "оба > 0\n";
else                        // ⚠️ относится к if(b > 0), а не к if(a > 0)!
    std::cout << "b <= 0\n";
```

## Часть 4. `if-else if-else` (цепочка)

Используется, когда вариантов больше двух. Проверка идёт **сверху вниз**, выполняется **первая** истинная ветка, остальные пропускаются.

```cpp
#include <iostream>

int main() {
    int score;
    std::cout << "Введите баллы (0-100): ";
    std::cin >> score;

    if (score >= 90) {
        std::cout << "Оценка: A\n";
    } else if (score >= 80) {
        std::cout << "Оценка: B\n";
    } else if (score >= 70) {
        std::cout << "Оценка: C\n";
    } else if (score >= 60) {
        std::cout << "Оценка: D\n";
    } else {
        std::cout << "Оценка: F\n";
    }

    return 0;
}
```

**Порядок важен!** Если написать `if (score >= 60)` первым, то для `score = 95` сработает именно эта ветка, и мы получим `D` вместо `A`. Цепочка должна идти от самого «сильного» условия к самому «слабому».

**Синтаксис:**
```
if (условие1) {
    ...
} else if (условие2) {
    ...
} else if (условие3) {
    ...
} else {
    ...   // необязательно
}
```

`else` в конце — необязателен. Если ни одна ветка не сработала и `else` нет, просто ничего не выполняется.

## Часть 5. Тернарный оператор `?:`

Компактная замена `if-else`, **возвращающая значение**. Форма:

```
условие ? значение_если_истина : значение_если_ложь
```

```cpp
#include <iostream>

int main() {
    int a = 7, b = 12;

    // Максимум из двух
    int max = (a > b) ? a : b;
    std::cout << "max = " << max << "\n";   // 12

    // Минимум
    int min = (a < b) ? a : b;
    std::cout << "min = " << min << "\n";   // 7

    // Модуль числа без <cmath>
    int x = -42;
    int abs_x = (x >= 0) ? x : -x;
    std::cout << "|x| = " << abs_x << "\n"; // 42

    // Чётность как строка
    int n = 5;
    std::cout << ((n % 2 == 0) ? "чётное" : "нечётное") << "\n";

    return 0;
}
```

**Типы в ветках** должны быть совместимы (компилятор найдёт общий тип). Пример с разными типами:

```cpp
int a = 5;
double b = 2.5;
// double и int → общий тип double
double r = (a > 3) ? a : b;   // r = 5.0 (тип double, значение 5)
```

**Вложенный тернарный оператор** (используйте осторожно — читаемость падает):

```cpp
int score = 85;
char grade = (score >= 90) ? 'A'
           : (score >= 80) ? 'B'
           : (score >= 70) ? 'C'
           : 'F';
std::cout << grade << "\n";   // B
```

**Когда использовать:** для коротких выражений «выбрать одно из двух значений». Для сложной логики — `if-else if`.

## Часть 6. `switch`

`switch` сравнивает **целочисленное** выражение (или `char`, `bool`, `enum`) с набором констант и выполняет соответствующую ветку.

```cpp
#include <iostream>

int main() {
    int day;
    std::cout << "Введите номер дня недели (1-7): ";
    std::cin >> day;

    switch (day) {
        case 1:
            std::cout << "Понедельник\n";
            break;
        case 2:
            std::cout << "Вторник\n";
            break;
        case 3:
            std::cout << "Среда\n";
            break;
        case 4:
            std::cout << "Четверг\n";
            break;
        case 5:
            std::cout << "Пятница\n";
            break;
        case 6:
            std::cout << "Суббота\n";
            break;
        case 7:
            std::cout << "Воскресенье\n";
            break;
        default:
            std::cout << "Некорректный номер дня\n";
    }

    return 0;
}
```

### 6.1. `break` и «проваливание» (fallthrough)

Если не написать `break`, управление «проваливается» в следующий `case`. Иногда это **полезно** (объединение случаев), иногда — **ошибка**.

**Полезное проваливание** — несколько `case` с одинаковым действием:

```cpp
char op;
std::cin >> op;

switch (op) {
    case 'a':
    case 'A':                     // 'a' и 'A' обрабатываются одинаково
        std::cout << "буква A\n";
        break;
    case 'b':
    case 'B':
        std::cout << "буква B\n";
        break;
    default:
        std::cout << "другая буква\n";
}
```

**Случайное проваливание** — забыли `break`:

```cpp
switch (day) {
    case 1:
        std::cout << "Пн\n";      // нет break!
    case 2:
        std::cout << "Вт\n";      // для day=1 выведет и «Пн», и «Вт»
        break;
}
```

### 6.2. `default`

Ветка `default` срабатывает, если **ни один** `case` не совпал. Может стоять в любом месте, но традиционно — в конце. Необязательна, но полезна для обработки непредвиденных значений.

### 6.3. Ограничения `switch`

- Условие должно быть **целочисленного** типа (`int`, `char`, `bool`, `long`, `enum`), но **не** `double`/`float`/`std::string`.
- `case`-метки должны быть **константными выражениями** (литералы, `const`, `constexpr`), но не переменные.
- Нельзя сравнивать диапазоны (`case 1..5` — нет такого). Для диапазонов — `if-else if`.

```cpp
// НЕЛЬЗЯ:
// double x = 2.5;
// switch (x) { ... }          // ошибка: double

// НЕЛЬЗЯ:
// int a = 1;
// switch (n) { case a: ... }  // ошибка: a — не константа
```

### 6.4. `switch` с `char`

```cpp
char grade;
std::cin >> grade;

switch (grade) {
    case 'A': std::cout << "Отлично\n";   break;
    case 'B': std::cout << "Хорошо\n";    break;
    case 'C': std::cout << "Удовл.\n";    break;
    case 'D': std::cout << "Плохо\n";     break;
    default:  std::cout << "Неизвестно\n";
}
```

### 6.5. `switch` с `bool`

```cpp
bool isRaining = true;
switch (isRaining) {
    case true:  std::cout << "Взять зонт\n"; break;
    case false: std::cout << "Можно без зонта\n"; break;
}
```

Это допустимо, но обычно для `bool` проще `if-else`. `switch` по `bool` — редкость.

### 6.6. `switch` с фигурными скобками в `case` (локальные переменные)

Если в `case` нужно объявить переменную, оберните ветку в `{}`:

```cpp
switch (n) {
    case 1: {
        int temp = n * 10;          // локальная переменная внутри case
        std::cout << temp << "\n";
        break;
    }
    case 2:
        std::cout << "два\n";
        break;
}
```

Без скобок компилятор может пожаловаться на «jump to case label crosses initialization».

## Часть 7. Сравнение `if-else if` и `switch`

| | `if-else if` | `switch` |
|---|---|---|
| Тип условия | любое (`bool`, сравнения, `double`, строки) | только целочисленный/`char`/`bool`/`enum` |
| Диапазоны | да (`x >= 1 && x <= 5`) | нет (только точные значения) |
| Константы в ветках | любые выражения | только константные |
| Читаемость при многих равноправных вариантах | хуже | лучше |
| Проваливание | нет | есть (нужен `break`) |

**Практическое правило:** много точных значений одного целочисленного выражения → `switch`; сравнения/диапазоны/разные типы → `if-else if`.

## Часть 8. Частые ошибки и подводные камни

### 8.1. `=` вместо `==`

```cpp
int x = 5;
if (x = 0) { ... }    // присваивание! Условие всегда false
if (x == 0) { ... }   // правильное сравнение
```

Защита: некоторые пишут `if (0 == x)` — тогда случайное `=` вызовет ошибку компиляции. Но современные компиляторы предупреждают о `if (x = 0)`, так что главное — читать предупреждения.

### 8.2. Сравнение `double`

```cpp
double a = 0.1 + 0.2;
if (a == 0.3) { ... }            // почти всегда false!
if (std::fabs(a - 0.3) < 1e-9) { ... }   // правильно (нужен <cmath>)
```

`double` нельзя сравнивать на точное равенство из-за погрешности представления.

### 8.3. Смешанное сравнение signed/unsigned

```cpp
int a = -1;
unsigned int b = 1;
if (a < b) { ... }   // a преобразуется в unsigned → 4294967295, условие false!
```

Решение — явное приведение: `if (static_cast<long long>(a) < static_cast<long long>(b))`.

### 8.4. Забытый `break` в `switch`

Самая частая ошибка. Если `break` не нужен намеренно (проваливание), добавьте комментарий `// fallthrough`, чтобы читатель и компилятор поняли, что это не опечатка.

### 8.5. Точка с запятой после `if`

```cpp
if (x > 0); {                 // ⚠️ точка с запятой завершает if!
    std::cout << "положительное\n";   // выполнится ВСЕГДА
}
```

### 8.6. «Висячий else»

Уже разобрано: `else` привязывается к ближайшему `if`. Всегда используйте `{}`.

### 8.7. Пустой блок `if`

```cpp
if (x > 0) { }                // ничего не делает — почти всегда ошибка
```

### 8.8. Условие-константа

```cpp
if (true)  { ... }            // всегда выполняется
if (false) { ... }            // никогда не выполняется
```

Иногда полезно для отладки (временно отключить блок), но в рабочем коде — признак ошибки.

### 8.9. `switch` по `double`

Не компилируется. Для `double` — только `if-else if` с допуском.

### 8.10. `case` с переменной

```cpp
int k = 3;
switch (n) {
    case k: ...               // ошибка: k не константа
}
```

## Часть 9. Комплексные практические примеры

### Пример 1. Определение знака числа

```cpp
#include <iostream>
#include <cmath>     // std::fabs

int main() {
    double x;
    std::cout << "Введите число: ";
    std::cin >> x;

    // Порядок: сначала проверяем «почти ноль» с допуском,
    // затем положительное/отрицательное
    if (std::fabs(x) < 1e-9) {
        std::cout << "Ноль\n";
    } else if (x > 0) {
        std::cout << "Положительное\n";
    } else {
        std::cout << "Отрицательное\n";
    }
    return 0;
}
```

### Пример 2. Проверка високосного года

```cpp
#include <iostream>

int main() {
    int year;
    std::cout << "Введите год: ";
    std::cin >> year;

    // Високосный: делится на 4, но не на 100, ИЛИ делится на 400
    bool leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);

    if (leap) {
        std::cout << year << " — високосный\n";
    } else {
        std::cout << year << " — не високосный\n";
    }
    return 0;
}
```

### Пример 3. Калькулятор на `switch`

```cpp
#include <iostream>
#include <cmath>     // fabs

int main() {
    double a, b;
    char op;
    std::cout << "Введите: a op b (например: 3 + 4)\n";
    std::cin >> a >> op >> b;

    switch (op) {
        case '+':
            std::cout << a + b << "\n";
            break;
        case '-':
            std::cout << a - b << "\n";
            break;
        case '*':
            std::cout << a * b << "\n";
            break;
        case '/':
            if (std::fabs(b) < 1e-9) {
                std::cout << "Деление на ноль!\n";
            } else {
                std::cout << a / b << "\n";
            }
            break;
        default:
            std::cout << "Неизвестная операция\n";
    }
    return 0;
}
```

### Пример 4. Классификация символа через `switch` с проваливанием

```cpp
#include <iostream>

int main() {
    char c;
    std::cout << "Введите символ: ";
    std::cin >> c;

    switch (c) {
        case 'a': case 'e': case 'i': case 'o': case 'u':
        case 'A': case 'E': case 'I': case 'O': case 'U':
            std::cout << "Гласная\n";
            break;
        case '0': case '1': case '2': case '3': case '4':
        case '5': case '6': case '7': case '8': case '9':
            std::cout << "Цифра\n";
            break;
        default:
            std::cout << "Другой символ\n";
    }
    return 0;
}
```

### Пример 5. Тернарный оператор для «безопасного» минимума

```cpp
#include <iostream>

int main() {
    int a, b, c;
    std::cin >> a >> b >> c;

    // Вложенные тернарные: минимум из трёх
    int min = (a < b) ? ((a < c) ? a : c) : ((b < c) ? b : c);
    std::cout << "min = " << min << "\n";

    // Максимум из трёх
    int max = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);
    std::cout << "max = " << max << "\n";

    return 0;
}
```

### Пример 6. Комбинирование условий с `&&` и `||`

```cpp
#include <iostream>

int main() {
    int age;
    bool student;
    std::cout << "Возраст: ";
    std::cin >> age;
    std::cout << "Студент? (1/0): ";
    std::cin >> student;

    // Скидка: пенсионеры (>=65) ИЛИ студенты младше 25
    bool discount = (age >= 65) || (student && age < 25);

    if (discount) {
        std::cout << "Скидка предоставляется\n";
    } else {
        std::cout << "Скидки нет\n";
    }
    return 0;
}
```

## Часть 10. 15 упражнений на отработку

**Упражнение 1.** Пользователь вводит целое число. Выведите, положительное оно, отрицательное или ноль. Используйте `if-else if-else`.

**Упражнение 2.** Пользователь вводит два числа `a` и `b`. Выведите большее из них через тернарный оператор, затем — через `if-else`.

**Упражнение 3.** Пользователь вводит число. Определите, чётное оно или нечётное. Используйте `%` и `if-else`.

**Упражнение 4.** Пользователь вводит баллы (0–100). Выставьте оценку по шкале: `≥90 → A`, `≥80 → B`, `≥70 → C`, `≥60 → D`, иначе `F`. Используйте цепочку `if-else if-else`.

**Упражнение 5.** Пользователь вводит номер месяца (1–12). Выведите название месяца через `switch` с `break`. Обработайте некорректный номер через `default`.

**Упражнение 6.** Пользователь вводит один символ. Через `switch` определите: это гласная (`a,e,i,o,u` в обоих регистрах), согласная (остальные буквы) или не буква. Используйте проваливание для объединения случаев.

**Упражнение 7.** Пользователь вводит год. Определите, високосный ли он: делится на 4, но не на 100, ИЛИ делится на 400. Используйте логические операторы `&&`, `||`, `!=` и `%`.

**Упражнение 8.** Пользователь вводит три числа. Найдите максимум из трёх. Решите двумя способами: (а) вложенными `if-else`, (б) вложенными тернарными операторами.

**Упражнение 9.** Пользователь вводит `a` и `b` (целые). Проверьте, делится ли `a` на `b` нацело, **без риска деления на ноль**: используйте короткое замыкание `b != 0 && a % b == 0`. Выведите результат.

**Упражнение 10.** Пользователь вводит два `double`. Сравните их: если `|a - b| < 1e-9`, выведите «равны», иначе — какое больше. (Нужен `<cmath>` и `std::fabs`.)

**Упражнение 11.** Пользователь вводит номер дня недели (1–7). Через `switch` выведите, рабочий это день или выходной. Сгруппируйте `case 1..5` и `case 6..7` через проваливание. Некорректный номер — через `default`.

**Упражнение 12.** Пользователь вводит символ операции (`+ - * /`) и два числа. Выполните операцию через `switch`. Для `/` проверьте деление на ноль через `std::fabs(b) < 1e-9`. Некорректную операцию обработайте в `default`.

**Упражнение 13.** Пользователь вводит возраст и наличие студенческого билета (1/0). Скидка даётся, если возраст ≥ 65 **ИЛИ** (студент **И** возраст < 25). Выведите, положена ли скидка. Используйте `&&` и `||` со скобками.

**Упражнение 14.** Пользователь вводит целое число. Определите его знак **и** чётность одним тернарным оператором, выводящим одну из строк: `"положительное чётное"`, `"положительное нечётное"`, `"отрицательное чётное"`, `"отрицательное нечётное"`, `"ноль"`. Подсказка: вложенные тернарные + отдельная проверка нуля через `if`.

**Упражнение 15.** Пользователь вводит `int x` и `unsigned int y`. Напишите **корректное** сравнение `x < y`, приведя оба к `long long` через `static_cast`. Сравните с «наивным» `x < y` и объясните в комментарии, почему результаты могут отличаться при `x = -1, y = 1`.

## Итог

- Сначала — базовая конструкция `if`: выполняет блок, если условие истинно.
- Условие в C++ — это любое выражение, приводимое к `bool`; `0` → `false`, ненулевое → `true`. Логические `&&`, `||`, `!` и операторы сравнения — строительные блоки условий; учитывайте приоритет и короткое замыкание.
- `if-else`, `if-else if-else` — универсальные инструменты для любых условий.
- `?:` — компактный выбор одного из двух **значений**.
- `switch` — для сравнения целочисленного выражения с набором **констант**; помните про `break` и проваливание.
- Главные ловушки: `=` вместо `==`, сравнение `double` на точное равенство, смешанное signed/unsigned, забытый `break`, «висячий else», точка с запятой после `if`.

Все перечисленное опирается только на уже изученное: переменные, ввод-вывод, операции, типы и преобразования. Никаких циклов, массивов, функций, классов, ссылок и указателей — только ветвления.
