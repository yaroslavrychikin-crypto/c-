## Часть 1. Теоретическое введение в C++ с примерами

### 1.1. Что такое C++ и как работает программа

C++ — это **компилируемый язык программирования**. Это означает, что написанный вами текст (исходный код) не может быть выполнен компьютером напрямую. Сначала специальная программа — **компилятор** — переводит ваш код в машинные инструкции (исполняемый файл), и только потом этот файл можно запустить .

Процесс выглядит так:
`ваш_код.cpp` → **Компилятор (g++)** → `исполняемый_файл` → **Запуск**

### 1.2. Первая программа: разбор каждой строки

Создайте файл `main.cpp` и вставьте в него следующий код. Ниже — подробный разбор каждого элемента.

```cpp
// Это директива препроцессора. Она сообщает компилятору:
// "Подключи библиотеку iostream (input/output stream)".
// Без неё мы не сможем выводить текст на экран или читать ввод.
#include <iostream>

// int main() — это главная функция. С неё начинается выполнение ЛЮБОЙ программы на C++.
// int означает, что функция вернёт целое число (код завершения) операционной системе.
int main() {
    // std::cout — это объект, представляющий стандартный поток вывода (обычно консоль).
    // Оператор << ("положить в поток") отправляет текст в этот поток.
    // std::endl — означает "конец строки" и заодно сбрасывает буфер вывода (заставляет текст появиться немедленно).
    std::cout << "Привет, мир!" << std::endl;

    // return 0; — сообщает операционной системе, что программа завершилась успешно.
    // Ноль традиционно означает "без ошибок". Любое другое число — код ошибки.
    return 0;
}
```

**Что здесь важно понять новичку:**
- `std::` — это пространство имён (namespace). В C++ много готовых функций и объектов, и `std::` указывает, что мы берём `cout` именно из стандартной библиотеки, а не откуда-то ещё.
- Точка с запятой `;` — обязательный признак конца инструкции. Пропуск `;` — одна из самых частых ошибок начинающих.
- Фигурные скобки `{ }` определяют **блок кода** — границы функции, цикла или условия.

### 1.3. Переменные и типы данных

Переменная — это именованная область памяти, в которой хранится значение определённого типа. В C++ тип указывается **явно** при объявлении.

```cpp
#include <iostream>
#include <string> // Подключаем библиотеку для работы со строками

int main() {
    // int — целое число (обычно 4 байта). Подходит для счёта, возрастов, количества.
    int age = 25;

    // double — число с плавающей точкой (дробное). Для цен, измерений, вычислений.
    double price = 19.99;

    // char — один символ. Обратите внимание: символ в ОДИНАРНЫХ кавычках.
    char grade = 'A';

    // bool — логический тип. Принимает только true (истина) или false (ложь).
    bool isStudent = true;

    // std::string — строка текста (требует #include <string>). В ДВОЙНЫХ кавычках.
    std::string name = "Иван";

    // Выводим значения. Переменные можно комбинировать с текстом в одном потоке.
    std::cout << "Имя: " << name << std::endl;
    std::cout << "Возраст: " << age << std::endl;
    std::cout << "Цена: " << price << std::endl;
    std::cout << "Оценка: " << grade << std::endl;
    std::cout << "Студент? " << isStudent << std::endl; // true выведется как 1, false как 0

    return 0;
}
```

**Практическое замечание:** C++ — язык со **статической типизацией**. Если вы объявили `int age`, то позже не сможете записать в неё строку `"двадцать"`. Компилятор выдаст ошибку. Это кажется строгим, но именно эта строгость отлавливает множество ошибок ещё до запуска программы.

### 1.4. Ввод данных от пользователя

Программа, которая только выводит текст, — это скучно. Для чтения ввода используется `std::cin` (console input) и оператор `>>`.

```cpp
#include <iostream>
#include <string>

int main() {
    std::string userName;
    int userAge;

    // Выводим приглашение (prompt), чтобы пользователь понял, что от него хотят.
    std::cout << "Введите ваше имя: ";

    // std::cin >> userName; — читает одно "слово" (до пробела) из консоли и кладёт в переменную.
    std::cin >> userName;

    std::cout << "Введите ваш возраст: ";
    std::cin >> userAge; // Читает число. Если ввести буквы, программа может уйти в бесконечный цикл (это тема для отдельного разговора).

    // Проверяем условие: если возраст меньше 18, выводим одно, иначе — другое.
    if (userAge < 18) {
        std::cout << "Привет, " << userName << "! Ты ещё юн." << std::endl;
    } else {
        std::cout << "Привет, " << userName << "! Ты уже взрослый." << std::endl;
    }

    return 0;
}
```

**Важное отличие `cin` от `cout`:** стрелочки `>>` направлены **от** консоли **в** переменную (ввод), а `<<` — **из** переменной **в** консоль (вывод).

### 1.5. Управляющие конструкции: if и циклы

**Условие `if`** позволяет выполнять код только при определённом условии. Операторы сравнения: `==` (равно), `!=` (не равно), `<`, `>`, `<=`, `>=`. Обратите внимание: `=` — это присваивание, а `==` — сравнение.

```cpp
int score = 85;

if (score >= 90) {
    std::cout << "Отлично" << std::endl;
} else if (score >= 70) {      // проверяется, только если первое условие ложно
    std::cout << "Хорошо" << std::endl;
} else {
    std::cout << "Нужно подтянуть" << std::endl;
}
```

**Цикл `for`** используется, когда известно количество повторений.

```cpp
// Синтаксис: for (инициализация; условие; изменение)
// 1. int i = 0 — создаём счётчик.
// 2. i < 5 — пока условие истинно, выполняем тело.
// 3. i++ — после каждой итерации увеличиваем счётчик на 1.
for (int i = 0; i < 5; i++) {
    std::cout << "Итерация номер " << i << std::endl;
}
```

**Цикл `while`** используется, когда количество повторений заранее неизвестно и зависит от условия.

```cpp
int countdown = 3;

// Пока countdown больше нуля — выполняем блок.
while (countdown > 0) {
    std::cout << countdown << "..." << std::endl;
    countdown--; // Уменьшаем на 1. Без этой строки цикл будет бесконечным!
}
std::cout << "Поехали!" << std::endl;
```

### 1.6. Функции: как не повторять код

Функция — это именованный блок кода, который можно вызывать многократно. Это основа структурирования программ.

```cpp
#include <iostream>

// Объявление функции: return_type имя_функции(параметры)
// int — функция вернёт целое число.
// a и b — параметры (входные данные).
int add(int a, int b) {
    // Возвращаем сумму. Результат подставляется туда, где функция была вызвана.
    return a + b;
}

// Функция с void ничего не возвращает — просто выполняет действие.
void printGreeting(std::string name) {
    std::cout << "Привет, " << name << "!" << std::endl;
}

int main() {
    // Вызов функции add с аргументами 5 и 3. Результат (8) сохраняется в result.
    int result = add(5, 3);
    std::cout << "5 + 3 = " << result << std::endl;

    // Вызов void-функции. Её результат нельзя сохранить, она просто "делает".
    printGreeting("Мария");

    return 0;
}
```

**Зачем нужны функции:** Представьте, что вам нужно трижды посчитать сумму двух чисел в разных местах программы. Без функции вы трижды напишете `a + b`. С функцией — трижды вызовете `add(...)`. Если логика изменится (например, нужно будет добавить проверку), вы измените её в одном месте — внутри функции.

## Часть 2: Настройка VS Code для C++ — для всех операционных систем

VS Code сам по себе — только редактор. Он **не содержит компилятора и отладчика**. Сначала нужно установить инструменты (toolchain), затем настроить редактор. Ниже — по каждой ОС отдельно.

---

### Windows: MinGW через MSYS2

В Windows нет предустановленного компилятора C++. Самый распространённый бесплатный вариант — MSYS2 с инструментами MinGW-w64.

**1. Установка MSYS2 и компилятора**

Скачайте установщик с официального сайта msys2.org и установите (по умолчанию в `C:\msys64`). После установки откройте терминал **MSYS2 UCRT64** (не cmd!) и выполните:

```bash
# Обновляем базу пакетов MSYS2
pacman -Syu

# Устанавливаем полный набор инструментов разработки:
# g++ (компилятор C++), gcc, gdb (отладчик), make и т.д.
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
```

Во время установки на вопрос о пакетах просто нажмите Enter (устанавливается всё по умолчанию).

**2. Добавление компилятора в PATH**

Чтобы `g++` был доступен из любого терминала и из VS Code:

1. Нажмите `Win + R`, введите `sysdm.cpl`, Enter.
2. Вкладка **Дополнительно** → **Переменные среды**.
3. В разделе «Переменные пользователя» найдите `Path` → **Изменить** → **Создать**.
4. Добавьте путь: `C:\msys64\ucrt64\bin`
5. ОК во всех окнах. **Закройте и заново откройте** терминал (cmd/PowerShell), чтобы изменения применились.

**3. Проверка**

В новом окне cmd или PowerShell:

```cmd
g++ --version
gdb --version
```

Должны отобразиться версии. Если пишет «не является внутренней или внешней командой» — PATH настроен неверно или терминал не перезапущен.

**4. Расширение и автонастройка в VS Code**

Установите расширение **C/C++** от Microsoft (`Ctrl+Shift+X` → поиск `C++` → Install).

Откройте папку проекта в VS Code, создайте `hello.cpp`, сделайте его активным. Нажмите **F5** → выберите **C/C++ (GDB/LLDB)** → затем **C/C++: g++.exe build and debug active file**. VS Code автоматически создаст `.vscode/tasks.json` и `.vscode/launch.json`.

**5. Ручной tasks.json (если авто не сработало)**

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "build with g++",
            "type": "shell",
            "command": "C:\\msys64\\ucrt64\\bin\\g++.exe",
            "args": [
                "-g",
                "${file}",
                "-o",
                "${fileDirname}\\${fileBasenameNoExtension}.exe"
            ],
            "group": { "kind": "build", "isDefault": true },
            "problemMatcher": ["$gcc"]
        }
    ]
}
```

Обратите внимание на `.exe` в конце — это расширение исполняемых файлов Windows.

> **Важно (после ноября 2024):** MSYS2 отключил автоматическое раскрытие wildcard-шаблонов в `mingw-w64`. Если вы раньше компилировали несколько файлов через `"${workspaceFolder}/*.cpp"` — это перестало работать. Нужно либо явно перечислять файлы, либо использовать CMake/Make.

### macOS: Clang через Xcode Command Line Tools

В macOS компилятор Clang и отладчик lldb обычно доступны после установки Command Line Tools.

**1. Проверка и установка**

```bash
clang --version
```

Если компилятор не найден или система предлагает установить инструменты — выполните:

```bash
xcode-select --install
```

Откроется системное окно установки. Согласитесь и дождитесь завершения. После этого проверьте:

```bash
clang++ --version
lldb --version
```

**2. Расширение и автонастройка в VS Code**

Установите расширение **C/C++** от Microsoft. Откройте `.cpp`-файл, нажмите **F5** → **C/C++ (GDB/LLDB)** → **C/C++: clang++ build and debug active file**. VS Code создаст конфигурацию с путём `/usr/bin/clang++`.

**3. Ручной tasks.json (если нужно)**

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "build with clang++",
            "type": "shell",
            "command": "/usr/bin/clang++",
            "args": [
                "-g",
                "${file}",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}"
            ],
            "group": { "kind": "build", "isDefault": true },
            "problemMatcher": ["$gcc"]
        }
    ]
}
```

Исполняемый файл в macOS без расширения — просто имя файла. Запуск: `./hello`.

**4. Особенности отладки на macOS**

- Используется **lldb**, а не gdb. Расширение C/C++ автоматически подставляет нужный отладчик.
- Если при первом запуске отладки macOS запрашивает разрешение на «управление компьютером» (Developer Tools Access) — введите пароль администратора и разрешите.
- Если F5 запускает, но не останавливается на точках останова — проверьте, что при компиляции был флаг `-g` (он есть в примере выше).

### Linux (Ubuntu / Debian / Fedora / Arch)

В Linux компилятор чаще всего уже есть или ставится одной командой. Ниже — для основных дистрибутивов.

**1. Установка по дистрибутивам**

**Ubuntu / Debian / Linux Mint:**

```bash
sudo apt update
# build-essential = g++, gcc, make и базовые библиотеки; gdb — отладчик
sudo apt install build-essential gdb
```

**Fedora / RHEL / CentOS Stream:**

```bash
# groupinstall ставит целую группу пакетов разработки
sudo dnf groupinstall "Development Tools"
sudo dnf install gcc-c++ gdb
```

**Arch / Manjaro:**

```bash
# base-devel — базовые инструменты сборки; gdb — отладчик
sudo pacman -S base-devel gdb
```

**openSUSE:**

```bash
sudo zypper install -t pattern devel_C_C++
sudo zypper install gdb
```

**2. Проверка**

```bash
g++ --version
gdb --version
```

**3. Расширение и автонастройка в VS Code**

Установите **C/C++** от Microsoft. Откройте `.cpp`-файл, нажмите **F5** → **C/C++ (GDB/LLDB)** → **C/C++: g++ build and debug active file**. VS Code создаст `.vscode/tasks.json` и `.vscode/launch.json` с путём `/usr/bin/g++`.

**4. Ручной tasks.json**

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "build with g++",
            "type": "shell",
            "command": "/usr/bin/g++",
            "args": [
                "-g",
                "${file}",
                "-o",
                "${fileDirname}/${fileBasenameNoExtension}"
            ],
            "group": { "kind": "build", "isDefault": true },
            "problemMatcher": ["$gcc"]
        }
    ]
}
```

**5. Быстрая проверка без настройки**

В терминале VS Code (`Ctrl+`` `):

```bash
g++ -g hello.cpp -o hello
./hello
```

Если увидели вывод программы — всё работает.

### Общие элементы для всех ОС

**Что делает автонастройка VS Code**

При первом нажатии F5 VS Code создаёт два файла в скрытой папке `.vscode`:

- `tasks.json` — как компилировать (команда, флаги, выходной файл).
- `launch.json` — как запускать отладчик (какая программа, какие аргументы, где искать исходники).

Их можно (и полезно) открыть и прочитать — там всё довольно прозрачно.

**Ключевые флаги компиляции**

| Флаг | Что делает |
|---|---|
| `-g` | Включает отладочную информацию. **Без него отладчик не работает.** |
| `-o имя` | Задаёт имя выходного файла |
| `-Wall -Wextra` | Включает предупреждения компилятора (рекомендуется новичкам) |
| `-std=c++17` | Выбирает стандарт языка (можно `c++20`, `c++23`) |

**Полезные горячие клавиши**

| Клавиши | Действие |
|---|---|
| `F5` | Запуск отладки |
| `Ctrl+Shift+B` | Сборка (без запуска) |
| `F9` | Поставить/снять точку останова |
| `F10` | Шаг с обходом (Step Over) |
| `F11` | Шаг с заходом в функцию (Step Into) |
| `Shift+F5` | Остановить отладку |

### Типичные проблемы и решения (по всем ОС)

**«g++: command not found» / «не является внутренней командой»**
Компилятор не установлен или не в PATH. Windows — проверьте `C:\msys64\ucrt64\bin` в Path и перезапустите терминал. macOS — `xcode-select --install`. Linux — установите пакет из раздела выше.

**Красные подчёркивания в `#include <iostream>`**
Расширение C/C++ не видит стандартные библиотеки. Нажмите `Ctrl+Shift+P` → `C/C++: Edit Configurations (UI)` → проверьте поле **Compiler path**. Оно должно указывать на реальный `g++`/`clang++`. После установки компилятора часто помогает перезапуск VS Code.

**F5 запускает, но точки останова игнорируются**
Почти всегда — компиляция без `-g`. Проверьте `args` в `tasks.json`. На macOS также убедитесь, что используется lldb (не gdb) — расширение делает это автоматически.

**«Unable to start debugging»**
Проверьте `launch.json`: поле `program` должно указывать на существующий исполняемый файл, а `miDebuggerPath` — на `gdb` (Windows/Linux) или `lldb` (macOS).

**Русские буквы выводятся «кракозябрами»**
Это кодировка терминала, а не ошибка C++. В Windows в старом cmd может помочь `chcp 65001` перед запуском, либо используйте Windows Terminal / PowerShell. В Linux и macOS с UTF-8 обычно всё сразу корректно.

**Отладка на Windows зависает на старте**
Иногда антивирус или Defender замедляет запуск gdb. Попробуйте добавить папку проекта в исключения.
